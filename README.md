# 历史地图绘图台

[打开地图](https://ukimafunado152036.github.io/historical-map-studio/)

在真实地理底图上绘制历史地图，使用独立 GitHub 项目保存。已有地图打开时会自动定位到地图范围或保存的视角。

## 新增功能

- 左上角“打开项目”：切换独立地图；连接授权后可新建、另存。
- “分享”：复制包含项目和当前视角的公开浏览链接，访客无需账号。
- “浏览模式”：隐藏编辑工具；点击要素查看名称和属性。“进入编辑”返回绘图台，实际编辑仍需仓库授权。
- “搜索 OSM 要素类型”：使用 iD Tagging Schema 的 1,594 种点、线、面预设，支持中文与标签搜索；可选择适用的点或范围表达。
- 按类型显示属性，并支持全部标签的添加、修改、移除。未知标签与额外属性会保留。预设覆盖不等于全部符号已完全复刻 OSM Carto，未专门适配的类型采用通用显示。
- 共用坐标节点拖动联动；可在“显示”页关闭。选中线后点击“在线节点处切分”，再点击中间节点，可保留属性分段。
- 继续支持圆角半径、节点编辑、撤销重做、现代地图和卫星参照。

## 保存位置

main 分支保存网页，map-data 分支保存地图文件；默认是 default.history-map.json。每次只加载一份地图，文件可按城市或区域分别保存。

地图和令牌不会自动写入 localStorage、IndexedDB 或本机文件。未提交修改在当前页面内存中。浏览器网络缓存与地图保存是两回事。

保存后的地图在公开链接中可被读取；当前没有草稿与发布版本分离。访客不能修改远端地图。令牌仅在当前页面会话中使用，不写入网址、源码或项目。

要保存，请在“GitHub 项目”中使用仓库所有者的细粒度访问令牌连接，仅选择本仓库，将 Contents 权限设为 Read and write。完成编辑后约 20 秒自动提交；关闭前可手动保存。界面以实际写入结果确认保存，冲突或失败不会当作成功。

## 兼容与范围

原有地图文件保持兼容。独立点线面、共点编辑及线段切分已支持，完整 OSM 关系编辑器和原版 Mapnik 渲染服务尚未接入。建成时间不属于本轮功能。

自然底图由 OpenFreeMap 提供，现代参考由 OpenStreetMap / Esri 提供。要素预设及中文翻译来自 [iD Tagging Schema](https://github.com/openstreetmap/id-tagging-schema)，ISC 许可见 ID-TAGGING-SCHEMA-LICENSE.txt。快照来源版本记录在 osm-presets.json。地图显示沿用 MapLibre，保留第三方许可。
